# Словарь

Единый язык проекта. Эти слова используются везде: в коде, в спеках, в интерфейсе, в
разговоре. Синонимов не заводим.

| Слово | Значение |
|---|---|
| **PR** | Пулл-реквест на GitHub. Идентифицируется парой `repo + number`. |
| **Факт** | Одна запись в журнале. Записи не изменяются и не удаляются. |
| **Журнал** | Append-only последовательность фактов. Единственный источник правды о том, что произошло. Живёт в SQLite. |
| **Тик** | Команда, которая приносит домену текущее время и настройки текущей попытки. Домен сам часы и настройки не читает. |
| **Wake-up** | Срабатывание фиксированного планировщика. Оно проверяет, наступил ли репозиторный темп, и только тогда посылает тик. |
| **Свип** | Одна именованная попытка пройти по всем открытым PR. Идёт раз в 6 часов и имеет `sweepId`. |
| **Инстанс** | Один запущенный процесс со своим журналом, настройками и `CODEX_HOME`. Владелец один, ролей нет. |
| **Токен GitHub** | PAT из окружения. Принадлежит инстансу, задаётся оператором и не хранится в журнале и не показывается в интерфейсе. |
| **Подключённый репозиторий** | `owner/name`, который оператор добавил в админке. Только по таким репозиториям идут тики. |
| **OpenAI Base URL** | Необязательная настройка endpoint Codex: нормализованный абсолютный HTTP(S) URL без credentials, query и fragment. Пустое значение означает официальный endpoint OpenAI. |
| **Снимок задачи** | Неизменяемые значения конкретной попытки, сохранённые при создании задачи. Изменяемые настройки после этого не перечитываются. |
| **Admission** | Правило, которое разрешает или запрещает заводить новую работу. |
| **Merge-gate** | Правило, которое разрешает или запрещает мерж. |
| **Evidence** | Полный снимок required inventory и всех check-run attempts для одного PR, head и свипа. |
| **Required identity** | Пара `context + appId`, которой GitHub идентифицирует обязательную проверку. Совпадения одного context недостаточно. |
| **Reconciliation** | Обязательный запрос текущего PR и check runs сразу после `PrCreated`; восстанавливает наблюдения, чей вебхук пришёл слишком рано. |
| **Report ID** | Идентификатор одного отчёта адаптера или исполнителя задачи. Повтор того же `type + reportId` не создаёт второй факт. |
| **Задача** | Запись очереди на исполнение эффекта. Живёт в SQLite рядом с журналом, берётся под аренду и переживает рестарт. |
| **Аренда** | Право одного исполнителя на задачу до истечения срока. Защищает от параллельного и повторного исполнения. |
| **Агент** | Codex, запущенный процессом. Меняет код и пушит ветку. |
| **Обязательная проверка** | Required identity из защиты целевой ветки GitHub. |

## Слова, которые не являются фактами

Это выводы, которые вычисляет `decide`. В журнал они не пишутся и от адаптеров не приходят:
`stale`, `complete`, `evidenceReady`, `progress`, `RECHECK_NEXT_RUN`, `passing`, `latest`.

Последнюю попытку для required identity выбирает домен по максимальной паре `createdAt`, затем
`id`. Адаптер передаёт все попытки и не вычисляет verdict.
