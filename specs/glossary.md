# Словарь

Единый язык проекта. Эти слова используются везде: в коде, в спеках, в интерфейсе, в
разговоре. Синонимов не заводим.

| Слово | Значение |
|---|---|
| **PR** | Пулл-реквест на GitHub. |
| **Факт** | Одна запись в журнале. Записи не изменяются и не удаляются. |
| **Журнал** | Append-only последовательность фактов. Единственный источник правды о том, что произошло. Живёт в Convex. |
| **Тик** | Команда, которая приносит домену текущее время. Домен сам часы не читает. |
| **Свип** | Проход по всем открытым PR. Идёт раз в 6 часов. |
| **Тенант** | Одна установка GitHub App. У тенанта может быть несколько репозиториев. |
| **Admission** | Правило, которое разрешает или запрещает заводить новую работу. |
| **Merge-gate** | Правило, которое разрешает или запрещает мерж. |
| **Воркер** | Отдельная программа, которая запускает Codex. Не функция Convex. |
| **Агент** | Codex, запущенный воркером. Меняет код и пушит ветку. |
| **Обязательная проверка** | Check run, помеченный обязательным в защите ветки GitHub. |

## Слова, которые не являются фактами

Это выводы, которые вычисляет `decide`. В журнал они не пишутся и от адаптеров не приходят:
`stale`, `complete`, `evidenceReady`, `progress`, `RECHECK_NEXT_RUN`.

Причина: посчитанный в адаптере вывод нельзя проверить таблицей. В Nucex они посчитаны в
`tools/gc/collect-ci-evidence.mjs` — и поэтому не проверяются.
